# FitTrack

### Aplikasi Manajemen dan Pemantauan Aktivitas Fisik serta Olahraga Harian Berbasis Android

## Deskripsi Project

**FitTrack** merupakan aplikasi mobile berbasis Android yang dirancang untuk membantu pengguna mencatat dan memantau aktivitas olahraga sehari-hari.

Aplikasi ini menyediakan fitur pengelolaan jadwal, target, serta riwayat olahraga berdasarkan jenis, tanggal, durasi, dan intensitas. Data aktivitas disimpan dalam database dan ditampilkan dalam bentuk riwayat serta statistik perkembangan untuk membantu pengguna membangun kebiasaan olahraga yang lebih teratur.

Aplikasi ini direncanakan dikembangkan menggunakan **Kotlin dan Jetpack Compose** sebagai project akhir mata kuliah Pengembangan Aplikasi Mobile (PAM) 2026.

## Teknologi yang Direncanakan

- **Kotlin** — Bahasa pemrograman aplikasi Android.
- **Jetpack Compose** — Pengembangan antarmuka aplikasi.
- **MVVM & Navigator Compose** — Arsitektur dan navigasi aplikasi.
- **REST API & MySQL** — Komunikasi dan penyimpanan data.
- **JWT & Refresh Token** — Autentikasi dan pengelolaan sesi pengguna.
- **Local File Storage** — Penyimpanan dan pembacaan file lokal.

Seluruh teknologi tersebut masih dalam tahap perencanaan dan akan diimplementasikan selama proses pengembangan.

## Fitur Utama yang Direncanakan

### Admin

- Mengelola kategori olahraga.
- Mengelola data olahraga.
- Melihat dan mengelola data pengguna.

### User

- Melakukan registrasi dan login.
- Melihat kategori dan daftar olahraga.
- Menambahkan, mengubah, menghapus, dan mencari aktivitas olahraga.
- Mengelola jadwal olahraga.
- Menentukan dan mengelola target olahraga.
- Melihat riwayat aktivitas olahraga.
- Melihat statistik perkembangan olahraga.
- Mengelola profil pengguna.

Seluruh fitur di atas merupakan rencana pengembangan dan belum diimplementasikan.

## Progress Pengembangan

### Penyusunan Software Requirements Specification (SRS)

**Status: In Progress**

Pada tahap ini dilakukan analisis kebutuhan dan penyusunan dokumen **Software Requirements Specification (SRS)** sebagai dasar perancangan dan pengembangan aplikasi FitTrack.

Dokumen SRS direncanakan mencakup:

1. **Introduction** — Tujuan dan ruang lingkup aplikasi.
2. **Overall Description** — Gambaran umum sistem, fitur, dan pengguna.
3. **System Features** — Kebutuhan fungsional dan alur sistem.
4. **External Interface Requirements** — Kebutuhan antarmuka dan integrasi.
5. **Other Nonfunctional Requirements** — Performa, keamanan, dan kualitas aplikasi.
6. **Other Requirements** — Kebutuhan tambahan sistem.
7. **Appendix A: Glossary** — Istilah dalam dokumen.
8. **Appendix B: Analysis Models** — Model analisis sistem seperti Use Case Diagram, Activity Diagram, dan ERD.
9. **Appendix C: Issues List** — Catatan isu dan keputusan pengembangan.
